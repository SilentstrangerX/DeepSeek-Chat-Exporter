# DeepSeek Chat Exporter

Chrome extension to export DeepSeek conversations with thinking content.

## Features

- **Full MD** — includes thinking blocks
- **Lean MD** — clean, paste-friendly, no thinking
- **JSONL** — one message per line, for training
- **Pretty JSON** — readable, structured
- **Fast** — uses DeepSeek's history API, no slow scrolling
- **Filename from conversation title**

## Install

1. Download from release and extract the zip file
2. Open `Browser extensions`
3. Enable **Developer mode**
4. Click **Load unpacked** → select the folder
5. Open `https://chat.deepseek.com`

## Usage

1. Click the **Export** button (bottom-right)
2. Pick a format
3. Click **Export**
